# Abd Elrahman Ali Mohamed Portfolio

A dependency-free personal portfolio built with HTML, CSS, and JavaScript.

## Publish with GitHub Pages

1. Create a new public repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, `.nojekyll`, the resume PDF, and this README.
3. Open the repository's **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. Visit `https://YOUR-GITHUB-USERNAME.github.io` after GitHub finishes publishing.

The current project uses relative asset paths, so it works as a GitHub Pages user site without a build step or package installation.

## Local preview

Open `index.html` directly in a browser. No server or dependency installation is required.
